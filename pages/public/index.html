ALERTAS AUTOMÁTICOS

Telegram

Os alertas são executados pelo GitHub Actions, sem servidor pago.

Mantemos o monitor Python existente: verifica a bilheteira às 10h, 11h e 12h (Lisboa) e envia mensagens quando aparecem jogos novos ou há alterações. Mantém também o resumo diário.

Configuração privada

O site é público e estático: para proteger o token do bot, as credenciais ficam nos Secrets do GitHub, nunca numa página acessível a todos.

Secrets necessários: TELEGRAM_BOT_TOKEN e TELEGRAM_CHAT_ID.

Como ativar os alertas?
  1. Cria um bot com @BotFather no Telegram.
  2. Abre o bot e envia /start.
  3. Obtém o teu ID de chat e guarda o token e o ID nos Secrets do repositório.
  4. Em Actions → Bilheteira Sporting CP, clica em Run workflow para testar.

🔒 Não introduzas nem publiques tokens do Telegram neste site ou nos ficheiros públicos.
